# 2026-07-31 NGMEMBERS Development Log

## Work Summary

PC에서 회원 카드의 회원번호를 드래그해 복사하려 할 때 카드가 펼쳐지거나 접히는 충돌을 해결했다. 카드 요약의 기존 클릭 동작은 유지하면서 회원번호만 독립적으로 선택할 수 있게 했다.

## Work Completed

- 카드 요약을 텍스트 선택이 가능한 컨테이너로 변경했다.
- 회원번호에 텍스트 선택 커서와 `user-select: text`를 적용했다.
- 회원번호에서 발생한 클릭이 카드 토글로 전달되지 않도록 이벤트를 분리했다.
- 카드 요약의 Enter·Space 키보드 토글과 포커스 표시를 유지했다.
- TypeScript 프로덕션 빌드와 기존 데이터 계층 테스트로 변경의 정적 안정성을 검증했다.

## Decisions

별도의 복사 버튼을 추가하면 화면과 조작 요소가 복잡해지므로, PC에서 익숙한 드래그 선택과 복사 방식을 지원하기로 했다. 카드의 나머지 영역은 기존처럼 클릭해 펼치고 접을 수 있게 유지했다.

## Current Status

회원번호 선택과 카드 토글의 이벤트 경계를 코드에 반영했고 프로덕션 빌드는 통과했다. 로컬 앱은 인증 세션이 없어 실제 회원 카드의 드래그 상호작용까지 자동 검증하지 못했다. 기존 Phase 4 테스트에는 이번 변경과 무관한 검색 문구 순서 불일치 1건이 남아 있다.

## Next Steps

- 로그인된 개발 환경에서 PC 드래그 선택을 최종 확인한다.
- 실제 배포는 이번 작업 범위에 포함하지 않았다.
